# Experiment 01 - MNIST Handwritten Digit Classification using ANN

## Objective
Build and train an Artificial Neural Network (ANN) to classify handwritten digits from the MNIST dataset.

## Dataset
- MNIST Handwritten Digits
- 60,000 Training Images
- 10,000 Testing Images
- Image Size: 28 × 28 pixels

## Tools & Libraries
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Scikit-learn

## Results
- Model trained successfully.
- Test accuracy achieved approximately **98%**.
- Performance evaluated using:
  - Accuracy and Loss plots
  - Confusion Matrix
  - Classification Report
  - Prediction visualization

## Files
- `MNIST_Classification.ipynb` – Jupyter notebook
- `mnist_model.keras` – Trained model
- `outputs/` – Generated plots
